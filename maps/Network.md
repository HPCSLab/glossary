# Network（ネットワーク）

> 計算機の間でデータを高速に受け渡すための、ネットワークの技術、プログラミングインタフェース、通信ライブラリを扱う。

## まず読む
- [[RDMA]] — 双方のOSを介さずに[[NIC|ネットワークアダプタ]]がメモリ間でデータを直接転送する仕組みであり、HPCの通信の基礎である。

## 性能の基本
### 性能を表す量
- [[Latency]] — 一つのデータが届くまでの時間であり、小さな転送の性能を決める。
- [[Bandwidth]] — 単位時間あたりに運べるデータ量であり、大きな転送の性能を決める。
- [[Little's Law]] — バンド幅とレイテンシから、必要な並行度を見積もる法則である。
### 流量の制限
- [[Token Bucket]] — 平均の速さを制限しつつ短いバーストを許す流量の制御の仕組みであり、Linuxの `tc` やストレージのQoSで用いられる。

## RDMA
### 装置と仕組み
- [[NIC]] — 計算機をネットワークに接続するハードウェアであり、DMAでパケットを主記憶と直接やり取りする。InfiniBandではHCAと呼ぶ。
- [[RDMA]] — カーネルバイパスとゼロコピーにより、低遅延でメモリ間の転送を行う仕組みである。
### RDMAを提供するネットワーク
- [[InfiniBand]] — HPCで広く用いられる、RDMAを基本機能として備えたネットワークである。
- [[RoCE]] — Ethernet上でRDMAを実現するプロトコルであり、クラウドやGPUクラスタで用いられる。
### プログラミングインタフェースと拡張
- [[Verbs]] — RDMAを利用するための低水準のインタフェースである（libibverbs）。
- [[GPUDirect RDMA]] — NICがホストのメモリを経ずに[[GPU]]のメモリを直接読み書きできるようにする技術である。

## クラスタのネットワークの構成
- [[Dragonfly Topology]] — スイッチのグループを少数の長いケーブルで直接結ぶ、スーパーコンピュータのネットワークのトポロジであり、HPE Slingshotのシステムが用いる。
- [[Multi-Rail]] — 一つのノードに複数のNICを載せて別々の経路（レール）とし、ノード間の帯域を束ねる構成であり、GPUクラスタの配線の基本となる。

## 通信の抽象化層
- [[UCX]] — 多様なネットワークと共有メモリ、GPUメモリを共通のAPIで扱い、メッセージに応じて転送手段を自動で選ぶ通信フレームワークであり、Open MPIやMPICHの通信層となる。
- [[libfabric]] — ネットワークごとのプロバイダを通じて多様なネットワークを共通のAPIで扱う通信ライブラリであり、SlingshotやAWSのEFAの上でMPIの実装が用いる。

## 並列計算の通信
- [[MPI]] — 並列計算のためのメッセージ通信の標準規格である。
- [[Collective Communication]] — 全プロセスが参加する通信であり、そのアルゴリズムが性能を左右する。
- [[NCCL]] — GPUの間の集団通信を、NVLinkやInfiniBandなどの接続に合わせて行うNVIDIAのライブラリである。
- [[SHARP]] — 集団通信のリダクションをInfiniBandのスイッチの中で行い、Allreduceでネットワークを通るデータとノードの計算を減らす技術である。
- GPU間の直接接続である[[NVLink]]は[[Machine Learning Systems]]を参照。

## 通信性能の計測
- [[OSU Micro-Benchmarks]] — MPIやNCCLの二プロセス間の通信と集団通信のレイテンシとバンド幅を、メッセージサイズごとに測るベンチマークであり、ネットワークの実効性能の確認に用いる。

## RPC
- [[Mercury]] — HPC向けのRPCフレームワークであり、大きなデータはRDMAで転送する。
- [[Margo]] — Mercuryとユーザレベルスレッドを統合し、データサービスを逐次的に書けるようにするライブラリである。

## カーネルバイパスとオフロード
- [[DPDK]] — カーネルを経由せず、ユーザ空間でポーリングによりパケットを高速に処理するためのライブラリ群である。
- [[DPU]] — CPUのコアとNICを統合し、ネットワーク・ストレージ・セキュリティの処理をホストから肩代わりする装置である。
- [[NADINO]] — サーバレスのクラウドの関数間の通信を、DPUの上のネットワークエンジン（DNE）とRDMAに任せるデータプレーンである。

## ネットワーク越しのストレージ
- [[NVMe-oF]] — [[NVMe]]のコマンドをRDMAやTCP越しに用い、リモートのSSDを利用する規格である。
- [[NVMesh]] — RDMAでターゲットのCPUを介さずにリモートのSSDへアクセスする共有ブロックストレージである。
- ブロックストレージの全体は[[Storage]]を参照（[[iSCSI]]・[[NBD]]を含む）。
- 共有ファイルシステム（[[NFS]]、[[Parallel File System|並列ファイルシステム]]）は[[HPC Storage]]を参照。

## 研究成果の発表
- [[NSDI]] — ネットワークと分散システムの設計・実装・評価を扱う国際会議である。

## 関連する分野
- [[Parallel Computing]] — ネットワークを用いた並列計算を扱う。
- [[HPC Storage]] — ネットワーク越しに共有される分散・[[Parallel File System|並列ファイルシステム]]を扱う。
- [[Storage]] — ネットワーク越しのブロックストレージを含む、ストレージの全体を扱う。
- [[Distributed Systems]] — 故障や遅延のあるネットワーク上での協調を扱う。
- [[System Administration]] — DHCP、PXE、IPMIなど、クラスタの構築と管理に用いるネットワークの仕組みを扱う。
