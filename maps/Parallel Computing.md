# Parallel Computing（並列計算）

> 多数のプロセッサやノードを協調させて一つの計算を高速に行うための、プログラミングモデル、通信、実行環境を扱う。

## まず読む
- [[MPI]] — 分散メモリ環境におけるプロセス間通信の標準規格であり、HPCの並列プログラミングの基礎である。
- [[Compute Node]] — クラスタの中で、ジョブの計算を実際に実行するノードである。

## 計算機の構成
- [[Compute Node]] — クラスタを構成する計算機のうち、ジョブの計算を実行するノードである。
- [[SRAM]] — 速いが容量あたりの面積の大きいメモリであり、CPUのキャッシュやGPUの共有メモリに用いる。
- [[DRAM]] — 密度が高く安価な、主記憶に用いるメモリであり、定期的なリフレッシュを要する。
- [[NUMA]] — 主記憶がCPUソケットごとに分かれ、どのメモリにアクセスするかで速さが異なる構成である。
- [[PCIe]] — 計算ノードの中でCPUとGPU、SSD、[[NIC]]を結ぶ接続であり、その帯域が装置間の転送の上限となる。

## ジョブとソフトウェアの環境
- [[Slurm]] — ジョブスケジューラであり、MPIプログラムの起動にも用いる。
- [[PBS]] — `qsub` などで使うジョブスケジューラの系統であり、Miyabiなどが用いる。
- [[Spack]] — HPC環境でライブラリの多数の版と構成を管理するパッケージマネージャである。

## プログラミングモデル
- [[MPI]] — プロセスとメッセージ通信による分散メモリ並列である。
- [[OpenMP]] — 共有メモリ上のスレッド並列である。
- [[PGAS]] — 区切られた大域的なアドレス空間を片側通信で読み書きする、MPIと共有メモリの中間のモデルである。
- [[OpenSHMEM]] — put・getの片側通信を中心とするPGASのライブラリの標準規格であり、GPU向けにはNVSHMEMがある。

## MPIの実装
- [[Open MPI]] — 複数の実装を統合して生まれた、代表的なMPIの実装である（OpenMPとは別物）。
- [[MPICH]] — [[Argonne|アルゴンヌ国立研究所]]などが開発するMPIの実装であり、多くの企業の実装の基盤である。

## 言語処理系と実行時ライブラリ
- [[Omni Compiler]] — XcalableMPなどの指示文を含むC/Fortranを変換するコンパイラの基盤であり、R-CCSと筑波大学が開発する。
- [[Argobots]] — OSのスレッドより軽量なユーザレベルスレッドとタスクを提供する、HPC向けのスレッドの枠組みである。

## アクセラレータ
- [[GPU]] — 多数の演算器による並列処理に特化したプロセッサである。
- [[HBM]] — GPUなどが用いる、積層したDRAMによる高バンド幅のメモリである。
- [[APU]] — CPUとGPUを一つに統合し、同じメモリを共有するAMDのプロセッサである（MI300Aなど）。
- [[NVLink]] — NVIDIAのGPU同士をPCIeより大幅に高い帯域で直接結ぶ接続である。

## アクセラレータのプログラミング
- [[CUDA]] — GPUで汎用の計算を行うためのプログラミングモデルである。
- [[cuBLAS]] — BLASをNVIDIAのGPU向けに実装した線形代数のライブラリであり、行列積（GEMM）が中心である。
- [[OpenACC]] — 指示文を加えて、ループなどの処理をGPUに移すためのプログラミングの規格である。
- [[Ozaki Scheme]] — 行列を低精度の行列に分割し、低精度の行列演算器でFP64などの高精度の行列積を再現する手法である。

## 性能のモデルと指標
- [[Latency]] — 要求から結果が得られ始めるまでの時間であり、小さな転送の性能を決める。
- [[Bandwidth]] — 単位時間あたりに運べるデータ量であり、大きな転送の性能を決める。
- [[Little's Law]] — バンド幅・レイテンシ・並行度の関係を与える法則である。
- [[Roofline Model]] — 演算性能とメモリのバンド幅から、計算が到達できる性能の上限を見積もるモデルである。

## 通信
- [[Collective Communication]] — 全プロセスが参加する通信であり、同期点として性能を左右する。
- [[InfiniBand]] — HPCで多用される高速ネットワークである。
- [[RDMA]] — 相手のCPUを介さずにメモリ間でデータを転送する仕組みである。
- [[GPUDirect RDMA]] — NICなどの[[PCIe]]の装置がGPUのメモリを直接読み書きできるようにする技術である。
- [[Dragonfly Topology]] — スイッチのグループを少数の長いケーブルで直接結ぶ、スーパーコンピュータのネットワークのトポロジである。
- ネットワークの技術と通信ライブラリの全体は[[Network]]を参照。

## 並列I/O
- [[MPI-IO]] — MPIの一部として定められた並列ファイルI/Oのインタフェースである。
- [[Collective IO]] — 全プロセスのI/Oをまとめ、少数の集約役が大きな読み書きを行う二段階I/Oである。
- [[Access Pattern]] — N-NとN-1など、多数のプロセスによる読み書きのパターンである。
- [[Darshan]] — アプリケーションのI/Oのアクセスパターンを小さな負担で記録するツールである。
- [[Recorder]] — 並列I/Oの呼び出しを層ごとに一つずつ記録するトレースのツールである。
- [[IOR]] — 並列I/Oの帯域を測るベンチマークである。
- [[Parallel File System|並列ファイルシステム]]を含む全体は[[HPC Storage]]を参照。

## 並列性能の評価
- [[Parallel Efficiency]] — 速度向上が投入資源に対してどれだけ理想に近いかを示す指標である。
- [[Strong Scaling]] — 問題の大きさを固定してプロセス数を増やす評価方法である。
- [[Weak Scaling]] — プロセスあたりの問題の大きさを固定する評価方法である。
- [[Amdahl's Law]] — 逐次部分が強スケーリングの上限を決めることを示す法則である。
- [[Gustafson's Law]] — 問題を大きくすれば速度向上が資源に比例しうることを示す法則である。

## 性能解析の道具
- [[perf]] — ホットスポットの特定やハードウェア性能カウンタの計測に用いる。
- [[RDTSC]] — タイムスタンプカウンタを読む命令であり、短い処理の時間を少ない負担で測るために用いる。

## スーパーコンピュータ
- [[Fugaku]] — 理化学研究所と富士通が開発したスーパーコンピュータであり、2020年から2021年にTOP500で首位であった。
- [[Pegasus]] — 筑波大学のスーパーコンピュータであり、各ノードにGPUとOptane永続メモリを搭載する。
- [[Sirius]] — 筑波大学のスーパーコンピュータ（PACS12.0）であり、CPUとGPUがHBM3を共有するMI300Aを搭載する。
- [[Miyabi]] — 筑波大学と東京大学が共同運営するJCAHPCのスーパーコンピュータであり、GH200を搭載する。

## 性能ランキング
- [[TOP500]] — LINPACKの性能でスーパーコンピュータを順位付けした一覧である。
- [[LINPACK]] — 密な連立一次方程式を解く計算で演算性能を測るベンチマークである（HPL）。

## 計算資源の提供と支援の体制
- [[HPCI]] — 富岳と全国の大学などのスーパーコンピュータを結ぶ共用の計算基盤であり、利用の申請の窓口でもある。
- [[RIKEN]] — 富岳を運用する計算科学研究センター（R-CCS）を持つ、日本の総合的な研究所である。
- [[Argonne]] — Auroraを運用し、MPICH、Mercury、Darshanなどを開発する米国DOEの国立研究所である。
- [[LLNL]] — El Capitanを運用し、Slurm、Spack、Fluxなどを開発する、核兵器の安全保障を担う米国DOE/NNSAの国立研究所である。
- [[ORNL]] — 世界初のエクサスケール機Frontierを運用する米国DOEの国立研究所である。
- [[HAIRDESC]] — GPUを中心とするスーパーコンピュータのプログラム開発と人材育成を支援する、2025年設立の拠点である。
- [[AI for Science]] — 機械学習をシミュレーションや実験と組み合わせて科学研究を加速する取り組みであり、富岳NEXTなどの次世代機の目標である。
