# Parallel Computing（並列計算）

> 多数のプロセッサやノードを協調させて一つの計算を高速に行うための、プログラミングモデル、通信、実行環境を扱う。

## まず読む
- [[MPI]] — 分散メモリ環境におけるプロセス間通信の標準規格であり、HPCの並列プログラミングの基礎である。

## プログラミングモデル
- [[MPI]] — プロセスとメッセージ通信による分散メモリ並列である。
- [[OpenMP]] — 共有メモリ上のスレッド並列である。

## アクセラレータ
- [[GPU]] — 多数の演算器による並列処理に特化したプロセッサである。
- [[CUDA]] — GPUで汎用の計算を行うためのプログラミングモデルである。

## 通信
- [[Collective Communication]] — 全プロセスが参加する通信であり、同期点として性能を左右する。
- [[InfiniBand]] — HPCで多用される高速ネットワークである。
- [[RDMA]] — 相手のCPUを介さずにメモリ間でデータを転送する仕組みである。

## 並列I/O
- [[MPI-IO]] — MPIの一部として定められた並列ファイルI/Oのインタフェースである。
- [[Parallel File System]] — 並列I/Oを受け止めるストレージ側の仕組みである（[[Storage]]を参照）。

## 性能評価
- [[Latency]] — 要求から結果が得られ始めるまでの時間であり、小さな転送の性能を決める。
- [[Bandwidth]] — 単位時間あたりに運べるデータ量であり、大きな転送の性能を決める。
- [[Little's Law]] — バンド幅・レイテンシ・並行度の関係を与える法則である。
- [[Parallel Efficiency]] — 速度向上が投入資源に対してどれだけ理想に近いかを示す指標である。
- [[Strong Scaling]] — 問題の大きさを固定してプロセス数を増やす評価方法である。
- [[Weak Scaling]] — プロセスあたりの問題の大きさを固定する評価方法である。
- [[Amdahl's Law]] — 逐次部分が強スケーリングの上限を決めることを示す法則である。
- [[Gustafson's Law]] — 問題を大きくすれば速度向上が資源に比例しうることを示す法則である。

## 性能解析
- [[perf]] — ホットスポットの特定やハードウェア性能カウンタの計測に用いる。

## 実行環境
- [[Slurm]] — ジョブスケジューラであり、MPIプログラムの起動にも用いる。
