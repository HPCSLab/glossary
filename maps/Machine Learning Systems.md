# Machine Learning Systems（機械学習システム）

> 大規模な機械学習、特にLLMの学習と推論を支える計算機、ソフトウェア、メモリとストレージの仕組みを扱う。

## まず読む
- [[LLM]] — 大規模言語モデルの仕組みと、推論のプリフィル段階とデコード段階の性質の違いを示す。

## 言語モデルの基礎
- [[LLM]] — 次のトークンを予測して文章を生成する、Transformerに基づく大規模な言語モデルである。
- [[Embedding]] — 単語などの対象を意味の近さを保つベクトルで表すものであり、ベクトル検索や推薦にも用いられる。

## 計算機とメモリ
- [[GPU]] — 多数の演算器による並列処理に特化したプロセッサであり、機械学習の計算の主力である。
- [[NVLink]] — GPU同士を高い帯域で直接結び、複数のGPUに分割したモデルの通信を支える接続である。
- [[HBM]] — [[DRAM]]を積層して幅の広いインタフェースで接続する、高バンド幅のメモリである。
- [[APU]] — CPUとGPUが同じメモリを共有するAMDのプロセッサである。
- [[DGX Spark]] — 128GBの統合メモリを持つ小型のAI用計算機であり、メモリバンド幅は273GB/sにとどまる。
- [[Cerebras]] — ウェハ全体を一つのチップとし、モデルの重みをオンチップの[[SRAM]]に置いて推論を高速化するAI用の計算機である。

## プログラミングとフレームワーク
- [[CUDA]] — NVIDIAのGPUで汎用の計算を行うためのプログラミングモデルである。
- [[PyTorch]] — テンソルの演算と自動微分を中心とする、深層学習の標準的なフレームワークである。
- [[NCCL]] — NVIDIAのGPUの間で集団通信を行うライブラリであり、分散学習の勾配の集約に用いる。
- [[Megatron-LM]] — テンソル並列とパイプライン並列でLLMを多数のGPUに分割して学習するNVIDIAのソフトウェアである。

## 推論システム
- [[KV Cache]] — 過去のトークンのキーとバリューを保持するキャッシュであり、推論のメモリ消費の主要因である。
- [[TTFT]] — 要求から最初のトークンまでの時間であり、ITLやスループットとともに推論の性能を表す。
- [[vLLM]] — PagedAttentionでKVキャッシュを効率的に管理する推論エンジンである。
- [[Quantization]] — 重みを少ないビット数で表し、モデルのメモリ使用量と読み出す量を減らす手法である。

## モデルの配布と形式
- [[Hugging Face]] — モデルとデータセットを共有するHubと、それを利用するTransformersなどのライブラリである。
- [[safetensors]] — コードを含まず、必要なテンソルだけを読み込めるように、モデルの重みを保存するファイル形式である。
- [[ONNX]] — 機械学習のモデルをフレームワークに依存しない共通の形式で表す規格であり、ONNX Runtimeで実行できる。

## 検索拡張
- [[Vector Database]] — 埋め込みのベクトルを格納し、近いベクトルを近似最近傍探索で高速に探すデータベースである。
- [[RAG]] — 外部の文書を検索して言語モデルに与え、重みに含まれない知識を使えるようにする手法である。

## GPUへのデータ転送
- [[GPUDirect RDMA]] — [[NIC]]などの装置がGPUのメモリを直接読み書きできるようにする技術である。
- [[GPUDirect Storage]] — 記憶装置とGPUのメモリの間で直接データを転送する技術である。
- [[BaM]] — GPUのスレッドが[[NVMe]] SSDへのアクセスを直接発行するシステムである。

## 研究成果の発表
