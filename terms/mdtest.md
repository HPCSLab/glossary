# mdtest

> MPIで起動した多数のプロセスから並列にファイルやディレクトリの作成・属性取得・削除を行い、並列ファイルシステムのメタデータ性能を測るベンチマークである。

## 概要
mdtestは、クラスタのMPI環境で、[[Parallel File System|並列ファイルシステム]]に対して実行することを想定した[[Metadata|メタデータ]]性能のベンチマークであり、現在は[[IOR]]と同じリポジトリで保守されている。各プロセスが指定した数のファイルやディレクトリを作成し、その属性を取得（[[stat]]）し、削除する。それぞれの操作について、一秒あたりの操作数の最大、最小、平均、標準偏差を報告する。

主なオプションは次のとおりである。

| オプション | 意味 |
|---|---|
| `-n` | 各プロセスが作成・属性取得・削除するディレクトリとファイルの数 |
| `-F` / `-D` | ファイルのみ / ディレクトリのみを対象とする |
| `-u` | プロセスごとに別々の作業ディレクトリを作る（指定しない場合は共有のディレクトリを用いる） |
| `-z` / `-b` / `-I` | 作成するディレクトリの木の深さ / 分岐の数 / 各ディレクトリに置く項目の数 |
| `-w` / `-e` | 作成した各ファイルに書き込む / 各ファイルから読み込むバイト数 |
| `-C` / `-T` / `-r` | 作成 / 属性取得 / 削除の段階だけを実行する |

## どこで出てくるか
mdtestは、データの帯域を測るIORとともに、[[IO500]]の構成要素となっている。mdtestは、ディレクトリの構造（共有のディレクトリか、プロセスごとのディレクトリか、木の深さと分岐の数）を変えながら、こうしたメタデータの処理能力を測る。
