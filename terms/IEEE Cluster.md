# IEEE Cluster

> クラスタ計算機とHPCのシステムを主な対象とする国際会議であり、正式名称は IEEE International Conference on Cluster Computing である。

## 概要
IEEE Clusterは、IEEE Computer Societyとその高性能計算の技術委員会（TCHPC）が主催する国際会議であり、毎年秋に開催される。2026年の会議は、9月22日から25日に米国バージニア州アレクサンドリアで開催される。

扱う題材は、クラスタ計算機のシステムソフトウェア、並列プログラミング、[[MPI]]などの通信、ジョブスケジューリング、[[Parallel File System|並列ファイルシステム]]を含むストレージとI/O、性能評価など、HPCシステムの実践的な側面に重点がある。HPCシステムの実装と評価を伴う研究と相性がよく、ストレージやI/Oに関する論文も多く採録される。

## どこで出てくるか
研究室での経験としては、IEEE Clusterには学生が筆頭著者として論文を通した例が比較的多く、査読付きの国際会議への最初の投稿先として現実的な目標となっている。[[SC]]や[[FAST]]と比べて採録の難度は低いが、HPCシステムの分野で認知された会議であり、業績としての評価も得られる。投稿の時期は春であり、国内の研究会で発表した内容を発展させて投稿する流れが一般的である。
