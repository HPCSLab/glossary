# HDD（ハードディスクドライブ）

> 高速に回転する磁性体の円盤（プラッタ）に、磁気によってデータを記録する、機械的な動作を伴う記憶装置である。

## 概要
HDDは、1956年にIBMが最初の製品を出荷して以来、計算機の主要な二次記憶装置であった。データは、回転するプラッタの表面に、わずかに浮いた読み書きヘッドによって記録される。ヘッドはアームの先にあり、アームを動かして目的のトラックにヘッドを移動させる。

ある位置のデータを読むには、ヘッドを目的のトラックに移動させる時間（シーク時間）と、目的の位置がヘッドの下に回ってくるまでの時間（回転待ち時間）がかかる。このため、一回のアクセスにはミリ秒の単位の時間がかかる。回転数は、一般向けの製品で毎分5,400〜7,200回転、企業向けで15,000回転程度である。連続した領域を順に読み書きする場合は高い[[Bandwidth|バンド幅]]が得られるが、ランダムなアクセスでは機械的な移動の時間が支配的になり、性能が大きく低下する。容量あたりの価格は[[SSD]]より安く、2025年の時点で一台36TBの製品がある。トラックを瓦のように重ねて記録密度を上げるSMR（瓦記録）の方式は、容量を増やす一方で、書き込みとランダムなアクセスの性能を下げる。

## どこで出てくるか
HDDは、容量あたりの価格が安いため、大容量のアーカイブや、[[Parallel File System|並列ファイルシステム]]のデータを置く記憶装置として、現在も用いられる。多くのOSやファイルシステムの設計は、ランダムなアクセスが遅いというHDDの性質を前提としている。例えば、I/Oスケジューラによる要求の並べ替えや、[[LSM-Tree|LSM木]]のような書き込みを順次化するデータ構造である。SSDの研究や論文を読む際には、その設計がHDDのどの前提を見直したものかを意識すると理解しやすい。
