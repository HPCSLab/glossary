# FAST

> USENIXが主催する、ファイルシステムとストレージを専門とする国際会議であり、この分野で最も権威のある会議である。正式名称は USENIX Conference on File and Storage Technologies である。

## 概要
FASTは2002年に始まり、毎年2月頃に米国カリフォルニア州（近年はサンタクララ）で開催される。2026年のFAST '26は第24回にあたり、2月24日から26日に開催された。査読は二重盲検で行われ、著者応答の機会があり、アーティファクト評価も実施されている。採録される論文の数は限られ、研究の新規性、実装と評価の完成度、実システムへの影響が厳しく問われる。

扱う題材は、[[File System|ファイルシステム]]、[[SSD]]などの記憶装置、[[Crash Consistency|クラッシュ整合性]]、キャッシュ、[[Object Storage|オブジェクトストレージ]]や分散ストレージ、データの信頼性など、ストレージに関わるあらゆる層にわたる。産業界からの参加と投稿も多く、実際の製品やサービスの知見に基づく論文も採録される。本ノート群で参照した[[FEMU]]の論文もFASTで発表されたものである。

## どこで出てくるか
ストレージの研究者にとって、FASTは最も重要な発表の場であり、関連研究の調査でもまずFASTの論文を確認する。FASTの論文は、ストレージ研究でどのような問題設定と評価が求められるかを知る最良の手本であり、新メンバーは過去の採録論文を読むことから始めるとよい。USENIXの会議の論文と発表の動画は、公式サイトで無償公開されている。
