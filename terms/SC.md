# SC

> HPCの分野で最大かつ最も権威のある国際会議であり、毎年11月に米国で開催される。正式名称は The International Conference for High Performance Computing, Networking, Storage, and Analysis である。

## 概要
SCは、1988年に始まり、ACMとIEEE Computer Societyが共催している。かつてはSupercomputingと呼ばれていた。2026年のSC26は、11月15日から20日にシカゴで開催される。数百人の有志が約三年をかけて準備する大規模な会議であり、参加者は一万人を超える。

技術論文（technical papers）の採択率はおおむね20%程度であり、HPCの分野で最も難関の会議の一つである。論文のほかに、ワークショップ、チュートリアル、ポスター、学生向けのプログラムがある。また、大規模並列計算の顕著な成果に贈られるACM Gordon Bell Prizeの授与や、スーパーコンピュータの性能ランキングであるTOP500の発表（年二回のうちの一回）も行われる。会場には、世界中の研究機関、大学、企業が展示ブースを出し、最新の計算機システムや研究成果を紹介する。

## どこで出てくるか
SCの論文は、アプリケーション、アルゴリズム、プログラミングモデル、システムソフトウェア、[[Parallel File System|並列ファイルシステム]]を含むストレージとI/O、ネットワーク、性能評価など、HPCのあらゆる分野にわたる。HPCの研究者にとって、SCで論文が採録されることは大きな業績である。SCへの論文の投稿は難度が高いが、併設のワークショップやポスターは、学生が国際会議で発表し、分野の研究者と交流する機会として利用しやすい。
